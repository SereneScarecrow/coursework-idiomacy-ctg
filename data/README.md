# Структура data

- **Исходный датасет находится в файле dataset_maxi_literal.csv**
- Файлы **all_generated.csv** и **dataset_maxi_metrcis.csv** содержат исходный текст, оценки судьи и автоматические оценки. Они используются для проведения анализа.
- В папке dicts содержится словарь, использованный при вычислении метрики абстрактности-конкретности.
- В папке intermediate лежат промежуточные файлы
  - Папка generated содержит отдельные файлы генерации для каждой модели
  - Папка dataset содержит промежуточные стадии создания датасета (очистка от переносов, подсчет слов и буквализация).
  - Папка judge содержит отдлельные файлы по этапам для сравнения нескольких судей.
